# Моя візитка

Проста персональна сторінка: ім’я, короткий опис, навички та контакти.

## Технології

- HTML
- CSS
- Git і GitHub

## Запуск

1. Завантажте репозиторій.
2. Відкрийте файл `index.html` у браузері.

Окремий сервер не потрібен: сторінка статична.

## Перемикач теми

На гілці `experiment/theme-toggle` додано кнопку «Темна тема» / «Світла тема». Вона змінює кольори сторінки, а вибраний режим зберігається в браузері.

Файл `.env` містить лише вигаданий демонстраційний ключ і не потрапляє в репозиторій: його виключає `.gitignore`.
